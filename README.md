# R26-SE-040 — Buddy: Emotionally Intelligent Robot Dog

Final Year Research Project | SLIIT BSc (Hons) Information Technology — Software Engineering

## Project Overview

Buddy is an affordable, emotionally intelligent robotic dog designed for companionship and AI-assisted security.

The research combines offline voice interaction, facial recognition, emotion analysis, autonomous navigation, and security monitoring.

## Core Research Components

### 1. Offline Voice Interaction
Wake-word detection, speech recognition, intent processing, text-to-speech and conversational interaction, with an emphasis on offline functionality and privacy.

### 2. Facial Recognition and Emotion Analysis
Face recognition, emotion detection and mood tracking to support more context-aware human-robot interaction.

### 3. Autonomous Navigation and Security
Robot movement, obstacle detection, autonomous patrol and security-event alerting.

## Technology Stack

- Python
- Raspberry Pi
- ROS 2
- OpenCV
- Vosk speech recognition
- PyTorch / Machine Learning
- Sensors, motor drivers and servo control

## Research Objectives

- Develop an affordable robotic companion.
- Support natural offline human-robot interaction.
- Recognize faces and analyze emotional expressions.
- Enable autonomous navigation and security monitoring.
- Integrate the research components into a functional robotic platform.

# Buddy Voice Assistant

Buddy is a Python voice assistant created by Ashandth.

## Features

- Voice input using microphone
- Voice output using gTTS and pygame
- Optional emotion voice using pyttsx3
- Local AI chat using Ollama Llama 3.2
- Intent detection using TF-IDF and Logistic Regression
- Memory system
- Weather
- News
- Google search
- YouTube music
- Calculator
- Distance calculator
